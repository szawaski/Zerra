Export and import

Queries with streams. Download the products as CSV, edit it, and preview it as an import to see what would change. Neither side holds the file in memory: the Catalog service writes the CSV as the browser reads it, and reads the uploaded file as it arrives. A query changes nothing, importing would be commands.

Download

ExportProductsCsv returns a Stream, streamed from the Catalog service through the gateway.

Preview an import

PreviewProductImport(fileName, csv, maxPriceChangePercent) takes a Stream between two other arguments. Those go first, the file follows in the same request.
