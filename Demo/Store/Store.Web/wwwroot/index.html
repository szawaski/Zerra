A storefront on seven microservices

These pages are static HTML and JavaScript. Every query and command goes through one CQRS gateway on this site, which forwards it to the service that owns it, over encrypted TCP for most services and HTTP for Shipping. Each service keeps its own data store (or none, by design) and seeds it on startup. Some commands and events between services go through Kafka, RabbitMQ, or Azure Service Bus when they're running, and directly when they aren't.

What happens when you place an order

  1. The Orders page dispatches PlaceOrderCommand to the gateway, which forwards it to the Orders service.
  2. Orders calls the Catalog service's GetProductsByIDs query, so names and prices come from the catalog and not from the browser.
  3. The Orders command handler checks the order rules: at least one item, quantities from 1 to 100, no discontinued products.
  4. Orders sends ReserveStockCommand to the Inventory service and waits. If any product is short, Inventory throws, nothing is reserved, and the error comes back to this page.
  5. The order is saved in the Orders data store and the result is returned to the page.
  6. Shipping the order later publishes OrderShippedEvent. Both Inventory and Shipping subscribe to it: Inventory takes the units off the shelf, and Shipping creates a tracking number, entirely independently.

Things to try

  • Order 3 Standing Desks. Only 2 are in stock, so Inventory rejects the order.
  • Place an order, then open Inventory to see the reservation. Ship it and the units leave the shelf, and a shipment appears on the Shipping page.
  • Discontinue a product in the Catalog, then try to order it.
  • Add a product, restock it in Inventory, then order it.
  • Stop the Inventory service and try to place an order to see how the failure comes back.
  • Write a review as a customer who received the product, then as one who never ordered it, and compare the badges on the Reviews page.
  • Fill a cart, empty it, fill it again, and check it out. The Carts page lists every event in the cart's stream, and the order appears on the Orders page.
