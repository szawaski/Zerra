Shipping

Owned by the Shipping service, the only one hosted inside ASP.NET Core over HTTP/Kestrel instead of the raw TCP the other services use. It has no database of its own, either, it keeps its shipments in memory. Orders sends it CreateShipmentCommand when an order ships: a command and not an event, because the shipment has to be created once and an event would reach every replica of this service.
